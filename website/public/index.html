05 / GOOD TO KNOW

A few answers
before you start.

Need a hand?
support@buhuipao.com

What is Agent Console?

Agent Console is a local, open-source dashboard for Codex, Claude Code, and pi. It brings sessions, progress, alerts, native agent terminals, and workspace shells into one terminal and browser interface.

Is Agent Console free?

Yes. Agent Console is free and open source under your choice of the MIT or Apache-2.0 license. Your agent provider’s subscription or API charges still apply. Optional progress summaries use that provider too.

Does it replace my coding agent?

You keep using your installed Codex, Claude Code, or pi. Agent Console discovers saved sessions and resumes the provider’s native interface. Custom provider commands can include wrappers, proxies, and environment settings.

Where do my sessions and data live?

Agent Console runs on your machine and keeps its own state locally. Your coding agents continue to use their configured services. Progress summaries use the session’s own provider in a separate call; set AGENT_CONSOLE_SUMMARIZER=off to disable them. This public website does not connect to your console.

Can I use it from my phone?

Yes, when the phone can reach your running console. Configure the bind address and port, authenticate with the console’s token or HTTP Basic credentials, and use the responsive browser UI. Remote access needs a trusted network or a TLS reverse proxy. The phone does not host the agents.

Can it attach to an agent already running elsewhere?

Agent Console reconnects to live processes it launched and owns. For a session started in another terminal, it resumes from the provider’s saved transcript. Multiple console views share a terminal; an input lease controls which view can type.

What are the current limits?

Alerts reset when the console restarts. Shared terminals use the smallest attached viewport. pi does not report a waiting status, and its live status bridge needs a POSIX shell. Permanent archived-session cleanup is available on macOS and Linux in the current source. See the known limits and provider compatibility guide for details.
